# v0.10.1

A patch with one job: **the updater now covers your whole workspace, and
audits its own result.** v0.10.0's `agentback update` quietly under-covered
monorepos — three gaps found by upgrading two real workspaces the day it
shipped ([#50](https://github.com/ninemindai/agentback/issues/50)). If you
upgrade with `npx @agentback/cli@latest update`, this release is what makes
that command trustworthy on a workspace; nothing else changed.

## 🔧 Fixed

### `agentback update` — workspace coverage ([#50](https://github.com/ninemindai/agentback/issues/50))

- **The bump phase walks every workspace manifest**, not just the root
  `package.json` — pnpm (`pnpm-workspace.yaml` `packages:` globs) and
  npm/yarn (`workspaces`) layouts both. Sub-package `@agentback/*` pins no
  longer silently hold the old version (0.x caret ranges can't cross a
  minor, so a stale pin never errors — it just wins).
- **Advisory detection scans workspace sources.** The lazy ts-morph seam now
  adds each workspace package's `src/**` — an advisory whose trigger lives
  only in a workspace package fires instead of false-negativing by omission.
- **`pnpm-workspace.yaml` pins are rewritten** — `overrides`, `catalog`, and
  named `catalogs` entries move to the target with a line-targeted,
  formatting-preserving edit (quote style, alignment, and comments survive
  byte-for-byte). Flow-style blocks and unreadable ranges are *reported*,
  never guessed at. Version resolution reads every pin site as a distinct
  occurrence, so two blocks disagreeing about a version widen the migration
  window to the lowest — they can never silently narrow it.
- **A post-update audit fails loud.** After install, `update` re-derives the
  full pin surface *independently of the bump logic* (filesystem walk, deep
  manifest scan, raw YAML match, real `node_modules` versions) and exits
  non-zero listing every site still below target — including ones the bump
  itself couldn't see. A stale dependency tree gets its own remedy line
  naming your package manager's install command instead of a generic
  "fix and re-run".

No library packages changed behavior in this release; the lockstep bump
carries them at 0.10.1 unchanged.

AI 时代还需不需要 framework？

我觉得不但需要，而且会更需要。

AI coding 之后，framework 不只是服务人，也要服务 coding agent：让 agent 更容易理解系统边界、生成正确代码、验证行为、组合能力。

这也是我做 AgentBack 的原因。

AgentBack 是一个帮助 coding agent 开发 API 和 MCP 的 agentic interface framework，一箭双雕：

一方面，让 agent 更容易写对后端 API。
另一方面，让这些 API 天然变成 AI agent 能理解、组合和调用的能力。

如果你也觉得 AI 时代需要新的 framework 形态，欢迎帮忙点个 Star：
